### Data Sourcing challenge
This project fetches data on Coronal Mass Ejections (CME) and Geomagnetic Storms (GST) from the NASA API, and then merges and cleans the data for further analysis.
This program is divided into three parts, which need to be executed in order:

## Part 1: Request CME Data
This part fetches CME data from the NASA API.

## Part 2: Request GST Data
This part fetches GST data from the NASA API.

## Part 3: Merge and Clean the Data
Merged the CMA and GST data, clean it, and prepare it for export:
We created a new column that shows the difference between startTime_GST and startTime_CME called 'timeDiff'  that is used to show the mean and median.
